# Mi Primera App en React

Esta es mi primera aplicación en React, creada mientras aprendo los fundamentos de esta biblioteca.

## Sobre el proyecto

Una aplicación de tareas (Todo) sencilla que me permite:
- Agregar nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtrar tareas (todas, activas, completadas)
- Persistencia en localStorage

## Tecnologías

- React 18
- Vite
- CSS Modules
- Context API para estado global

## Scripts disponibles

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build para producción
npm run build

# Vista previa del build
npm run preview
```

## Aprendizajes

Este proyecto cubre los conceptos básicos de React:
- Componentes funcionales y props
- Estado con `useState`
- Efectos secundarios con `useEffect`
- Context API para evitar prop drilling
- Custom hooks para lógica reutilizable
- Portales para modales
- Formularios controlados
